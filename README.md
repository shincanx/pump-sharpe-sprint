A paper-trading bot for pump.fun's 6-hour replay: it buys young coins on strong buy flow (at least 70% buys, +4% momentum over 3 trades, still under 1.3x its create price) and rides winners with a trailing stop, pyramiding up 12% at a time while cutting losers at -7%.

## Run it

```sh
node cli/makefun.mjs grade-local --kit . --bot . --driver docker
```
